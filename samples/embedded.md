# Embedded ddot.it in Markdown

ddot.it triples can be authored inline. The plugin recognises three fence
labels — `ddot`, `ddot.it`, and `ddotit`.

```ddot
Project Eagle ..started in.. 2024
John Doe ..leads.. Project Eagle ,, ..since.. 2025
```

```ddot.it
Untyped link
Project Eagle .... Moonshot
```

```ddotit
Dirk Hagemann ..works at.. SAP ,,
..year.. 2010
..fictive.. yes
,,
```
